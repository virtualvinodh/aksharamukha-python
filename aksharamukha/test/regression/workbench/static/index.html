options reference

Reversible (Indic) - baseline conversions, no options

Viewer only - use the all-fanout button on a row in the Source Texts tab to generate more (2 rows per script: nativize true & false). Reversibility itself isn't generated separately here - pytest's TestConversionSampleRoundtrips checks every nativize=false row against a reversible target directly, so there's nothing to click for that. Only output is directly editable here.

Irreversible (Indic) - baseline conversions, no options

Viewer only - use the all-fanout button on a row in the Source Texts tab to generate more. No reverse round-trip here - these scripts aren't in GeneralMap.ReversibleScripts, so a round trip isn't expected to return the original text.

Roman Reversible - baseline conversions, no options

Viewer only - use the all-fanout button on a row in the Source Texts tab to generate more. Scripts in GeneralMap.RomanReversible (IAST, HK, Itrans, Velthuis, Titus, WX, RussianCyrillic, ISO) - pytest checks round-trips for these directly from the fanout data.

Roman Irreversible - baseline conversions, no options

Viewer only - use the all-fanout button on a row in the Source Texts tab to generate more.

Semitic - baseline conversions, no options

Viewer only - use the all-fanout button on a row in the Source Texts tab to generate more.

Post-options - grouped by script

One section per target script. Use the post-opts button on a Devanagari row in the Source Texts tab to generate full coverage - it expands every already-working option to every script it applies to, always at nativize=true (the only mode this test harness ever exercises). Doesn't touch the 32 multi-arg or 4 broken options, see the Direct Options tab for those.

Pre-options - grouped by script

One section per source script. Use the pre-opts button on a Devanagari row in the Source Texts tab to generate full coverage.

Direct Options - the ~32 multi-argument options

Options that need more than the text itself (a target script, a reverse flag, ...) to call correctly - see args. Viewer/editor only, no bulk generation here: each one's calling convention was individually discovered, not a uniform script × nativize grid.

Custom Cases - one full transliterate.process() call, hand-written

For cases the option tabs can't express: a specific source/target/nativize with any combination of pre-options AND post-options applied together. Backed by test_custom_cases.json, checked for real by TestCustomCases in testsuite.py.
